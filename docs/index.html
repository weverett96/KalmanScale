KalmanScale — Privacy Policy

Last updated: 2026-08-27

KalmanScale is a personal, single-user application built and operated by Will Everett for his own use. It is not a commercial product, is not distributed to other users, and does not have a public sign-up.

What data this app accesses

KalmanScale connects to the Whoop API (via OAuth2, with the developer's own Whoop account) to read daily energy expenditure data (physiological cycle data, including calories burned). It also stores daily body weight and estimated calorie intake, entered manually by the developer.

How the data is used

All data is used solely to compute a smoothed weight-trend estimate (via a Kalman filter) for the developer's personal use. Whoop data is never used for any other purpose.

How the data is stored

All data is stored locally in a SQLite database on hardware owned and controlled by the developer (a home server). It is not transmitted to, processed by, or shared with any third party, and is not sold, monetized, or used for advertising.

Data retention and deletion

Data is retained for as long as the app is in personal use. Whoop API access can be revoked at any time from the developer's Whoop account settings, which stops all further data access.
